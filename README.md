# homebrew-coffee

Homebrew tap for [`coffee`](https://github.com/mrthiti/coffee) — keeps your
Mac awake even with the lid closed.

## Install

```sh
brew tap mrthiti/coffee
brew install --cask coffee
```

## Uninstall

```sh
brew uninstall --cask coffee
```

Source code, issues, and full documentation live in the main repo:
[mrthiti/coffee](https://github.com/mrthiti/coffee).
